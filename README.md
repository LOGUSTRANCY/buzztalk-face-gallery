# Buzztalk Photo Gallery (Unique ID Based)

A privacy-friendly event photo gallery system where students can
retrieve their photos by entering a unique ID or scanning a QR code.

## Features
- No face recognition
- No biometric data
- Cloudflare R2 storage
- Cloudflare Workers backend
- Pinterest-style photo gallery

## Usage
1. Admin uploads photos tagged with a unique ID
2. Students enter the same ID to view their photos
